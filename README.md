# Gesture-Controlled-RC-Car.
A gesture controlled robotic car built with using an ACEBOTT ESP32 smart car platform. The vehicle in controlled through hand movements, combining motion sensing, wireless communication, embedded programming, and motor control. This project focused on modifying and programming the ACEBOTT platform to respond to gesture-based commands rather than relying on a traditional remote or app.

## Technologies used
- ACEBOTT ESP32 Smart Car Platform
- ESP32
- Motion/ Gesture Sensor
- ACECode / Arduino-compatible programming
- C / C++
- Wireless Communication
- Mecanum Wheels
- Embedded Systems

## How It Works
The project uses an ACEBOTT ESP32 robot car as the vehicle platform. Hand movements are detected by the gesture-control hardware and translated into directional commands. Those commands are sent to the ESP32-controlled car, which then controls the motors to move in the requested directions.
Examples:
- Tilt forward -> Move forward
- Tilt backward -> Move backward
- Title right -> Turn / Move right
- Tilt left -> Turn / Move left
